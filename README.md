# Svetainių Studija — Nojus & Oskaras

Welcome to our home base. This repository is where we build our business together — ideas, plans, and the code behind it all live here.

## Who we are

Two friends — **Nojus** and **Oskaras** — building a website studio (*svetainių studija*): we design and build websites for clients.

## What's in this repo

| Folder | Purpose |
| --- | --- |
| `docs/` | Business planning — ideas, decisions, meeting notes |
| `clients/` | One folder per client project (proposals, requirements, assets) |
| `site/` | Our own studio website (coming soon) |

## Getting started

1. Jot down ideas in `docs/ideas.md` — no idea is too small.
2. When we land a client, give them a folder under `clients/`.
3. When we're ready, our own site goes in `site/` — it's our best advertisement.

## Ground rules

- Work happens on branches, merged via pull requests — so we both see what's changing.
- Write things down. If it's not in the repo, it didn't happen.
- Have fun. This is ours.
