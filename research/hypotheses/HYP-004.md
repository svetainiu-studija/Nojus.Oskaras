Drafted 2026-08-28 from the first round's recorded findings (not from a new
interview — founders signed off via D-021, Option A). This is HYP-002's
mechanism with the stop geometry fixed: the stop scales with the coin's own
volatility instead of a fixed structural level, so the entry rule no longer
forbids its own trades. Parameters are **fixed** a priori.

```
ID: HYP-004
Name: Cross-sectional momentum leaders, volume-confirmed breakout, ATR-scaled stops (daily)
Setup (identical to HYP-002 unless stated):
  Daily bars.
  - Leader: 60-day return minus BTC's 60-day return in the top 5 of the
    point-in-time universe (fixed).
  - Breakout: close strictly above the max of the prior 20 closes (fixed),
    with volume >= 1.5x the prior 20-day average (fixed).
  - Not extended: close < 15% above EMA20.
  - BTC filter: BTC close > its 50-bar SMA.
  - Universe/listing age as before.
Entry rule:
  Buy at the next open. STOP = signal close - 2 x ATR(14)  (fixed k=2;
  Wilder ATR). Sanity cap: skip only if the stop distance exceeds 25% of
  price (declared guard against absurd sizing, not a selection filter -
  finding 3 from round 1: fixed-% caps reject the strategy's own trades).
Exit rules:
  Invalidation: the ATR stop, resting-stop execution (finding 2).
  Trail: once the trade has been >= +1R, trail at the 10-day low.
  Partial: 1/3 at 3R. RS exit: coin leaves the top half of the ranking.
  Time stop: 15 bars only if the trade never reached +1R.
  Regime exit: flatten if BTC closes below its 50-bar SMA.
Position sizing rule:
  Risk 1% of equity per trade (ATR distance defines size); D-015 caps.
Universe (pairs, timeframe):
  Point-in-time top-30 OKX spot, daily bars; same survivorship caveats.
Why it should work:
  Same mechanism as HYP-002 (documented cross-sectional momentum; slow
  capital rotation into attention leaders; squeezed shorts; anchored
  under-reaction). What changes: the stop now respects each coin's
  volatility, so risk-per-trade is constant while the entry's geometry is
  no longer self-contradictory. EXP-003's 4 permitted trades (+0.365 R,
  PF 2.95, stress-robust) are weak but consistent evidence the mechanism
  survives costs when it is allowed to trade.
What would make you abandon it:
  The pre-registered Sprint D decision rule (NOTES-SPRINT-D.md): <30 trades,
  expectancy <= 0, <4/7 folds, stress PF < 1.1, or p >= 0.05 vs random.
Machine provenance:
  Derived from EXP-001..004 findings; variants tried counter starts at the
  Sprint D pre-registration.
```
